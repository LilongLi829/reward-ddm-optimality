# Third-party redistribution policy

Public availability is not treated as blanket permission to redistribute or re-license third-party raw data or original-author code.

This repository therefore points users to authoritative source repositories and distributes only the derived/frozen analysis inputs required for the manuscript-facing reproduction where appropriate. Third-party raw/source payloads are not bundled solely because the corresponding article is open access.

An article-level Creative Commons license does not by itself establish the file-level license of every separately hosted dataset or code archive.
