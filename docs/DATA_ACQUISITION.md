# Authoritative data acquisition

Third-party raw data/original-author code are not automatically re-licensed by this repository.

## Hübner et al. (2021)
- Public OSF project: `https://osf.io/shq7m/`
- DOI: `10.1037/xhp0000957`
- Integrity reference used in the reanalysis for `data.csv`:
  `3828a7205549cc2e2235e6a125b7b18a04dacaabf11b3f38973ece0e4b3f4ded`

## Taylor, Brown & Evans (2025), Experiment 3
- Public OSF project: `https://osf.io/8s6pn/`
- DOI: `10.3758/s13423-025-02680-y`
- Final reconstruction uses the complete N=58 Experiment 3 sample.
- Participant identity must be keyed by `group::source_id`, not source ID alone.

## Evans, Bennett & Brown (2019)
- DOI: `10.3758/s13423-018-1536-4`
- The analysis provenance records the recovered posterior-derived input stage.
- Manuscript target: late decision threshold, blocks 11–20.

## Leng et al. (2021)

## Integrity procedure
Download third-party source materials from the authoritative locations above and preserve their original filenames and provenance. The public repository intentionally does not redistribute upstream raw/source archives whose file-level redistribution terms have not been established.
