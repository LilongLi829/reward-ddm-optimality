# Manuscript result audit

`MANUSCRIPT_RESULT_LEDGER.csv` is rebuilt by `run_all.py` from the study-specific checks.

The repository distinguishes manuscript-result reproduction from reconstruction of every historical raw-data/model-fitting pipeline. Hübner, TBE, Evans, and Bogacz include participant-level frozen inputs sufficient to recompute the manuscript-facing prediction errors and deterministic 10,000-resample bootstrap intervals. Leng confidence limits are checked from the archived analysis table distributed here.

All seven manuscript figures are regenerated by the five study-specific reproduction scripts. Existing PNG files may be deleted before running `python run_all.py`; the scripts recreate them.

For Hübner, TBE, Evans, and Bogacz, the public release uses a fixed bootstrap seed (`20260929`) so repeated runs return identical intervals. These deterministic intervals should be used in the final manuscript. Historical Monte-Carlo bootstrap endpoints from earlier working analyses may differ slightly because their original random-number state was not preserved.
