# Bogacz — cross-environment boundary evidence

**Role in manuscript:** boundary evidence for whether a single residual error-cost parameter generalizes across delay environments.

The public reproduction begins from frozen participant-by-held-out-condition predictions. The exact historical generator of the frozen q values is not independently reconstructed and is therefore not presented as a raw-to-q reproduction.

Run `python scripts/reproduce_bogacz.py`. Manuscript-facing prediction errors and condition summaries are regenerated from the frozen participant-level table.
