# Leng — mechanism/value-mapping boundary evidence

**Role in manuscript:** tests whether incentive effects are reducible to a single scalar residual error cost.

The archived tables contain participant-level/model-summary outputs from the original reanalysis pipeline: DDM incentive effects, held-out value mapping, and forward threshold prediction. The Subjective mapping is not relabeled as a literal one-parameter Mq model.

Run `python scripts/reproduce_leng.py`. The public package does not redistribute upstream raw data.
